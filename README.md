# 🌊 OSIS.Mailer

**Gmail, 네이버 메일 등 다양한 이메일 SMTP 서버에 연결하여 메일을 발송하는 C# 기반 라이브러리입니다.**

수지라(Sujira) 프로그램의 상용 메일 발송 기능을 위해 **2022년 약 2개월간 단독 개발한 프로젝트**입니다.  
2022년 7월 개발 완료 후 실제 서비스에 적용되어 현재까지 사용·유지보수되고 있습니다.

|-|-|-|

### 2.2. 주요 기능

|지원 기능 | 설명 |
|---|---|
| SMTP 메일 발송 | Gmail, 네이버, Daum(Hanmail 포함) 등 SMTP 서버를 통한 메일 발송 |
| 파일 첨부 및 전송 | 메일 발송 시 첨부파일 포함 |
| IMAP 메일함 관리 | 서버 메일함 접근 및 관리 |
| 사용자 지정 SMTP | SMTP 서버 주소, 포트, 인증 정보 등을 직접 설정하여 발송 |


### 2.3. SMTP 서버 설정

|메일 서비스|SMTP 서버|포트|보안 연결|
|-|-|-|-|
|Gmail|`smtp.gmail.com`|`587`|TLS|

|Daum 메일|`smtp.daum.net`|`465`|TLS / SSL|

## 📌 3. 사용 전 계정 설정

외부 SMTP 프로그램으로 메일을 보내려면 메일 제공업체에서 요구하는 **2단계 인증 및 앱 비밀번호 설정**이 필요할 수 있습니다.

### 3.1. Gmail

1. [Google 계정](https://myaccount.google.com/)에서 **2단계 인증**을 설정합니다.
2. 계정에서 앱 비밀번호 사용이 허용된다면 [Google 앱 비밀번호](https://support.google.com/accounts/answer/185833?hl=ko) 안내에 따라 앱 비밀번호를 생성합니다.
3. SMTP 서버 `smtp.gmail.com`, 포트 `587`(TLS/STARTTLS), Gmail 주소와 발급받은 앱 비밀번호를 설정합니다.

### 3.2. 네이버 메일

1. 네이버 메일의 **환경설정 → POP3/IMAP 설정**에서 사용할 SMTP 관련 설정을 확인하고 활성화합니다.
2. 네이버 계정의 **2단계 인증**을 설정합니다.
3. [애플리케이션 비밀번호](https://help.naver.com/service/5640/contents/8584?lang=ko&osType=COMMONOS)를 생성합니다.
4. SMTP 서버 `smtp.naver.com`, 포트 `587`(TLS) 또는 해당 설정에 맞는 `465`(SSL), 네이버 계정과 애플리케이션 비밀번호를 입력합니다.

### 3.3. Daum 메일

1. Daum 메일의 **설정 → IMAP/POP3 설정**에서 외부 메일 프로그램 이용을 활성화합니다.
2. 계정에 **2단계 인증**을 적용한 뒤 앱 비밀번호를 생성합니다.
3. SMTP 서버 `smtp.daum.net`, 포트 `465`(SSL/TLS), Daum 메일 주소와 앱 비밀번호를 설정합니다.

## 📌 4. POP3 미지원 배경

`OSIS.Mailer`는 **메일 발송에 SMTP**, **서버 메일함 접근·관리에 IMAP**을 사용하며 POP3는 지원하지 않습니다. IMAP과 POP3 모두 메일 수신에 활용되지만 서버 메일함을 관리하는 기능에서 차이가 있습니다.

### 4.1. POP3와 IMAP 비교

|비교 항목|POP3|IMAP|
|-|-|-|
|기본 목적|서버의 메일을 클라이언트로 가져오기|서버의 메일함에 접근하고 메시지 관리|
|서버 폴더 관리|표준 기능으로 제공하지 않음|메일함 조회·관리 지원|
|서버의 보낸메일함에 메시지 저장|지원하지 않음|`APPEND` 명령으로 메시지 추가 가능|

### 4.2. IMAP을 선택한 이유

2022년 개발 과정에서 **SMTP 발송 후 보낸메일함에 발송 메시지가 저장되지 않는 문제**를 발견했습니다.

POP3는 서버에 저장된 메시지를 가져오는 데 초점을 두지만, IMAP은 서버 메일함에 직접 접속하여 메시지를 추가하고 관리하는 기능을 제공합니다. 따라서 **발송 메시지의 사본을 서버 보낸메일함에 저장하는 설계**에 더 적합했습니다.

이러한 이유로 메일함 접근 프로토콜을 **IMAP으로 통일**하고 POP3를 지원 대상에서 제외했습니다.

**참고 표준:** · [RFC 9051 — IMAP4rev2](https://www.rfc-editor.org/rfc/rfc9051) · [RFC 6409 — 메일 제출](https://www.rfc-editor.org/rfc/rfc6409)
