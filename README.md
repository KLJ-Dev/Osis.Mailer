🌊 OSIS.Mailer
Gmail, 네이버 메일 등 다양한 이메일 서비스의 SMTP 서버에 연결하여 메일을 발송하는 C# 기반 도구입니다.
2022년 개발한 메일 발송 모듈을 기반으로 하며, 2022년 7월 완성 이후 수지라(Sujira) 프로그램에서 상용으로 사용 및 유지보수하고 있습니다. 2026년 `OSIS.Mailer`로 명칭을 변경했습니다.
<br />
📃 프로젝트 정보
1. 지원 SMTP 목록 > SMTP 설정 안내
메일 서비스	SMTP 서버	포트	보안 연결
Gmail	`smtp.gmail.com`	`587`	TLS/STARTTLS
네이버 메일	`smtp.naver.com`	`587` / `465`	TLS / SSL (설정별 상이)
Daum 메일	`smtp.daum.net`	`465`	SSL/TLS
> 위 표는 각 메일 서비스의 **공식 SMTP 연결 설정**을 정리한 것입니다. 모든 항목이 현재 배포 버전에서 테스트되었다는 뜻은 아닙니다. 특히 보안 연결 방식 및 포트 지원은 사용 중인 프로그램 버전에 따라 확인이 필요합니다.
공식 설정 문서
Gmail SMTP 설정
네이버 IMAP/SMTP 설정
네이버 POP3/SMTP 설정
Daum SMTP 서버 설정
2. 사용 전 참고사항 > Gmail · 네이버 메일 · Daum 메일 사용 방법
외부 SMTP 프로그램으로 메일을 보내려면 메일 제공업체에서 요구하는 2단계 인증 및 앱 비밀번호 설정이 필요할 수 있습니다.
Gmail
Google 계정에서 2단계 인증을 설정합니다.
계정에서 앱 비밀번호 사용이 허용된다면 Google 앱 비밀번호 안내에 따라 앱 비밀번호를 생성합니다.
SMTP 서버 `smtp.gmail.com`, 포트 `587`(TLS/STARTTLS), Gmail 주소와 발급받은 앱 비밀번호를 설정합니다.
> Google은 가능한 경우 **Google 계정으로 로그인(OAuth 기반 방식)**을 권장합니다. 앱 비밀번호는 계정 종류나 보안 정책에 따라 제공되지 않을 수 있습니다.
네이버 메일
네이버 메일의 환경설정 → POP3/IMAP 설정에서 사용할 SMTP 관련 설정을 확인하고 활성화합니다.
네이버 계정의 2단계 인증을 설정합니다.
애플리케이션 비밀번호를 생성합니다.
SMTP 서버 `smtp.naver.com`, 포트 `587`(TLS) 또는 해당 설정에 맞는 `465`(SSL), 네이버 계정과 애플리케이션 비밀번호를 입력합니다.
> 네이버는 **2025년 6월 24일**부터 POP3/IMAP/SMTP 접속 시 2단계 인증 및 애플리케이션 비밀번호를 요구합니다. [공식 공지](https://help.naver.com/notice/noticeView.help?lang=ko&noticeNo=22533&serviceNo=30029)
Daum 메일
Daum 메일의 설정 → IMAP/POP3 설정에서 외부 메일 프로그램 이용을 활성화합니다.
계정에 2단계 인증을 적용한 뒤 앱 비밀번호를 생성합니다.
SMTP 서버 `smtp.daum.net`, 포트 `465`(SSL/TLS), Daum 메일 주소와 앱 비밀번호를 설정합니다.
> **2025년 12월 1일**부터 Daum 메일 앱 비밀번호는 카카오계정이 아닌 **Daum 마이페이지 → 계정 보안**에서 발급·관리합니다. [Daum 공식 안내](https://cs.daum.net/faq/service/43/category/9234/detail/35948)
보안 유의사항: 일반 계정 비밀번호와 앱 비밀번호를 소스코드, 설정 예제, GitHub 저장소 및 개발 기록에 올리지 마세요. 이미 노출된 앱 비밀번호가 있다면 폐기하고 재발급해야 합니다.
3. 개발 기록
시기	개발 및 운영 이력
2022년 (약 3개월)	C# 기반 SMTP 메일 발송 기능 개발. Gmail·네이버 계정 인증, SMTP 보안 연결과 포트별 통신 문제 검토. IMAP을 이용한 보낸메일함 처리 방식 조사.
2022년 7월	메일 발송 모듈 개발 완료. 수지라(Sujira) 프로그램에 상용 적용. .NET Framework 대상 빌드 및 설치 패키지 의존성 점검.
2022년 7월 ~ 현재	수지라 프로그램에서 상업적으로 사용 중이며 유지보수 지속.
2026년	기존 메일 발송 모듈을 **`OSIS.Mailer`**로 명칭 변경하고 GitHub 프로젝트로 정리.
> 개발 기간 약 3개월, 상용 적용 및 현재 유지보수 여부는 프로젝트 개발자가 제공한 이력에 따릅니다. 2022년 당시 기록에 언급된 IMAP 관련 검토 내용은 현재 버전에 해당 기능이 구현되어 있음을 의미하지 않습니다.
